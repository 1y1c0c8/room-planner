# 房間擺設 Room Planner

用自己量的尺寸模擬房間與傢俱擺設。2D 精確定位，3D 走進去看看。

線上版：https://1y1c0c8.github.io/room-planner/

## 功能（v0.2）
- **空間＝專案**：矩形或逐牆輸入（含閉合誤差處理）、門（鉸鏈側、開向、開門範圍）
- **物品庫**（所有空間共用）：方塊／圓形傢俱、矩形／圓形地毯，尺寸到 0.1 cm，標籤與備註
- **外觀**：純色、照片貼頂面（四角透視校正，依量測尺寸拉正）、材質重複鋪貼
- **2D 擺放**：拖曳（1 cm／Shift 0.1 cm）、邊緣自動貼齊、旋轉、鎖定
- **以任意邊為基準設定距離**：點物件的邊 → 點牆／門框／其他物件的邊 → 輸入距離
- **牆面視圖（v0.2）**：點平面圖上的牆切換成立面圖，掛畫／海報（寬×高×厚度、照片貼正面）、窗戶（寬、高、窗台高度），門與靠牆傢俱側影一併顯示，可用天花板、地板、牆角、門框、傢俱頂面或其他畫的邊設定距離
- **量測線**、**擺法方案**（同一房間多種擺法）、復原／重做
- **3D**：環繞檢視、第一人稱走動（WASD＋滑鼠／手機搖桿、可調眼高）
- 資料存在瀏覽器（IndexedDB），可匯出／匯入備份檔在裝置間搬移

## 技術
純靜態網頁（ES modules，無建置步驟），Three.js 由 CDN 載入。部署在 GitHub Pages（main 分支根目錄），`git push` 即更新。
